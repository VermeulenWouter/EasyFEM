This folder contains all data collected from experiments (``raw``), treated and prepared for plotting (``input``), and model output (``output``). Note ``raw`` and ``input`` are not submitted with the manuscript, thus are empty. The ``output`` folder also is nearly empty but scripts provided in the ``source`` folder (same level as the folder this README is in) allow to generate the result files. As example, the output files for a hybrid model with 4% NiTiCo wire volume fraction and 4% prestrain is included.
